# Калькулятор зрелости 1.2

Упрощённый интерфейс · 16 октября 2026 года.

## Основной сценарий

1. Запустите `Калькулятор зрелости v1.2.exe`.
2. При необходимости укажите организацию и систему в верхней строке, выберите категорию. Дополнительные реквизиты находятся на вкладке «Данные для отчёта».
3. Заполните общую таблицу. Каждая оценка выбирается одним нажатием. Галочка слева включает или исключает направление. Столбец «Цель» позволяет повысить целевой уровень.
4. Нажмите «Сохранить комплект» и выберите ZIP-файл. В него войдут проект, Word-отчёт, Excel-таблица и опись. Следующие нажатия «Обновить комплект» обновляют выбранный архив без дополнительных окон.

Кнопка «Открыть» читает как отдельный `.uzi.json`, так и сохранённый ZIP-комплект: вручную распаковывать архив не нужно. После открытия ZIP кнопка «Обновить комплект» сохраняет изменения в этот архив.

Данные оценки автоматически сохраняются в локальную автокопию `Данные\Автосохранение.json` рядом с программой. Отдельный проект можно сохранить через «Ещё → Сохранить файл проекта». `Ctrl+S` сохраняет открытый JSON-проект или обновляет выбранный ZIP-комплект; для новой оценки без выбранного пути он предлагает сохранить проект JSON. Изменения в открытом файле требуют его сохранения; автокопия служит для восстановления текущей работы.

## Как отвечать

- Пустая ячейка — ответа нет. Оценка **0** — отдельный явно выбранный ответ.
- Наведите указатель на оценку: точное описание появится под таблицей и во всплывающей подсказке. Название критерия в шапке также содержит полное пояснение.
- Повторное нажатие на выбранную оценку снимает ответ.
- Нажмите название направления, чтобы открыть подробную анкету и комментарии с подтверждающими материалами. Вернуться можно вкладкой «Оценка».
- С клавиатуры: после фокуса на ячейке `0` — оценка 0, `5` — 0,5, `1` — 1; для обучения `3` — 0,3. `Delete` или `Backspace` снимает ответ. `Tab` переводит фокус дальше.
- Поиск над таблицей отбирает направления по названию или номеру. «Только незаполненные» скрывает завершённые и исключённые строки.

Восемь критериев сохраняют исходные формулировки и веса. Не выбирайте оценку только по её числу: используйте описание конкретного условия. Для обучения предусмотрены четыре значения; для остальных критериев — три.

## Если ответы повторяются

Раскройте «Повторяющиеся ответы», выберите направление-образец и нажмите «Повторить в пустых ячейках». Применяйте это действие, когда условия в направлениях действительно одинаковы.

Переносятся только выбранные ответы источника и только в пустые ячейки других включённых направлений. Уже введённые оценки, включая явный 0, сохраняются. Цели, исключения, комментарии и реквизиты не копируются. Пустые ответы источника остаются пустыми.

Внизу появится кнопка «Отменить заполнение». Отмена возвращает перенесённые ответы в прежнее состояние и сохраняет последующие ручные правки. Доступна отмена последнего переноса в текущем сеансе.

## Сохранение и отчёты

Кнопка «Сохранить комплект» сразу создаёт полный комплект. При неполной анкете он явно помечается как предварительный; пропуски перечисляются в описи. Пустая область оценки не позволяет создать комплект.

В меню «Ещё» доступны:

- новая оценка;
- сохранение файла проекта `.uzi.json` и «Сохранить как»;
- отдельный Word или Excel;
- «Сохранить комплект как…» для другого файла;
- «Выбрать состав комплекта…» для отключения отдельных отчётов и подробной проверки пропусков.

Сохранение завершается сообщением в нижней строке, без отдельной кнопки «ОК». При восстановлении автокопии путь ZIP не запоминается: откройте нужный ZIP или выберите файл при сохранении комплекта.

Профили организации `.org.json` из версии 1.1 поддерживаются. Их сохранение и загрузка находятся на вкладке «Данные для отчёта». Загрузка профиля не меняет систему, дату, категорию, ответы, цели, область оценки, подтверждающие материалы, заметки и номер документа.

## Расчёт и совместимость

21 направление × 8 критериев; `D = вес × оценка`, `P = ΣD`. Уровень определяется по порогу суммы и обязательным минимумам таблицы 3. `Узи` — среднее уровней включённых направлений, округлённое до двух знаков.

Формулы и данные не менялись. Незаполненные ответы для предварительного расчёта временно дают 0. Интервал `0,2 ≤ P < 0,225` трактуется как уровень 0, как в исходном калькуляторе. Цель проверяется отдельно по направлениям.

Проекты версий 1.0 и 1.1 открываются. Требования: Windows 10/11 и .NET Framework 4.8 или новее. Установка, интернет, Word и Excel для расчёта и создания отчётов не нужны. Рекомендуемое разрешение — от 1280 × 800.

Источник расчёта и формулировок: https://117fstec.credos.ru/maturity. Методика ФСТЭК от 07.08.2026: https://fstec.ru/files/1523/---7--2026-/3102/---7--2026-.pdf.

## Исходный код и проверки

В архиве комплекта находятся папки `Исходники` и `Проверки`. Сборка — скриптом `build.ps1`; используются WPF и стандартные библиотеки .NET Framework без сторонних пакетов.

Основная проверка, из корня распакованного комплекта:

```powershell
& '.\Калькулятор зрелости v1.2.exe' --self-test '.\Проверки\reference-cases.json' '.\Результат-проверки'
```

Проверка нового ввода без показа окон:

```powershell
& '.\Калькулятор зрелости v1.2.exe' --ui-self-test '.\Результат-проверки-интерфейса'
```

Результаты сохраняются в JSON. Проверки экспорта Office подтверждают структуру и значения; полная постраничная проверка Word ограничена отсутствием встроенного LibreOffice в среде сборки.
