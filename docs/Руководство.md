# Калькулятор уровня зрелости Узи / Пзи

Версия 1.0 · 16 октября 2026 года.

Локальное приложение для Windows по образцу калькулятора https://117fstec.credos.ru/maturity. Интернет для работы не нужен. Excel и Word не требуются для расчёта и создания отчётов.

## Запуск

1. Сохраните `Калькулятор зрелости.exe` в обычную папку, в которую разрешена запись. Если используете архив, сначала распакуйте его.
2. Запустите `.exe` двойным щелчком. Установка не требуется.
3. В разделе «Параметры оценки» укажите организацию, систему, исполнителя и дату.
4. Выберите категорию системы и включите применимые направления.
5. В разделе «Оценка направлений» заполните 8 критериев каждого направления. Названия в левой панели открывают нужное направление; поле над ними ищет по названию и номеру.
6. В разделе «Результаты и отчёты» посмотрите итог, профиль зрелости и рекомендации. Кнопка «Экспорт» создаёт Word `.docx` или Excel `.xlsx`.

Требования: Windows 10/11, .NET Framework 4.8 или новее. На компьютере, на котором приложение собрано, эта среда уже установлена. Рекомендуемое разрешение экрана — от 1280 × 800.

## Сохранение

- «Сохранить» записывает отдельный файл проекта `.uzi.json`. Его можно перенести на другой компьютер и открыть кнопкой «Открыть».
- Автокопия текущей оценки находится рядом с программой: `Данные\Автосохранение.json`. Она восстанавливается при следующем запуске.
- Восстановленную оценку сохраните в отдельный файл, если хотите хранить несколько оценок или версий.
- Перед созданием новой оценки или открытием другого проекта программа предлагает сохранить изменённую оценку. При закрытии изменённого именованного проекта предлагается сохранить изменения в его файл.
- Не переносите только `.exe`, если хотите перенести и последнюю автокопию: перенесите также папку `Данные` или предварительно сохраните отдельный проект.

Горячие клавиши: `Ctrl+S` — сохранить; `Ctrl+Shift+S` — сохранить как; `Ctrl+O` — открыть; `Ctrl+N` — новая оценка.

## Как считается результат

Встроены 21 направление и 8 критериев, формулировки градаций и веса исходного калькулятора. Для обучения доступны оценки 0 / 0,3 / 0,5 / 1; для остальных критериев — 0 / 0,5 / 1.

Взвешенный вклад критерия: `D = вес × оценка`. Сумма направления: `P = ΣD`. Уровень направления определяется одновременно по порогу суммы и обязательным минимумам таблицы 3. Итоговый показатель `Узи` — среднее текущих уровней включённых направлений, округлённое до двух знаков.

Категория задаёт минимум цели 1, 2 или 3. Цель отдельного направления можно повысить до 4. Смена категории устанавливает соответствующую цель для всех направлений.

Исключённое направление не входит в расчёт и счётчик заполнения; его ответы, цель и комментарии сохраняются. Если все направления исключены, показатель не рассчитывается и экспорт отчёта недоступен.

Незаполненный ответ отличается от выбранной оценки 0. Для предварительного расчёта незаполненные ответы временно дают 0. До заполнения всех включённых направлений результат и отчёты явно помечаются как предварительные. Достижение целей подтверждается по полностью заполненным направлениям.

Интервал `0,2 ≤ P < 0,225` трактуется как уровень 0, как в исходном калькуляторе. Уровень 4 требует регулярной внешней оценки — это отражено в обязательном минимуме критерия «Внешний аудит».

## Что входит в отчёты

**Word:** сведения об оценке, итог, диаграмма, сводка по 21 направлению, ответы по всем критериям, подтверждающие материалы и рекомендации.

**Excel:** листы «Сводка», «Ответы» и «Рекомендации». Числа записаны числовыми ячейками. Пользовательские комментарии записаны текстом.

## Источники и проверка

- Калькулятор и формулировки: https://117fstec.credos.ru/maturity
- Методика ФСТЭК от 07.08.2026: https://fstec.ru/files/1523/---7--2026-/3102/---7--2026-.pdf

Пороги и минимумы сверены с таблицей 3 методики. Значения `P` и уровня совпали с оригинальными расчётными функциями сайта для всех 8 748 допустимых заполненных комбинаций. Дополнительно проверены округление, пустые ответы, исключения, чтение и атомарная запись проектов, отклонение некорректных данных. DOCX/XLSX проверены средствами python-docx и openpyxl; интерфейс отрисован без показа окон. Полная постраничная проверка Word-отчёта ограничена отсутствием встроенного LibreOffice в среде сборки.

Это самостоятельное приложение. Результаты зависят от введённых сведений. Программа не передаёт оценки в интернет.

## Исходный код

В архиве комплекта папка `Исходники` содержит C#-код, иконку, манифест и `build.ps1`. Приложение использует WPF и стандартные библиотеки .NET Framework; сторонних пакетов нет. `Data.cs` содержит встроенные направления и критерии, `Model.cs` — расчёт и сохранение, `Reports.cs` — выгрузку, `App.cs` — интерфейс.

Для сборки выполните `build.ps1` в PowerShell. В Windows с установленным .NET Framework доступен использованный компилятор `csc.exe`; скрипт ищет его автоматически.

Папка `Проверки` в комплекте содержит эталонные комбинации и результат проверки. Повторный запуск проверки, из корня распакованного комплекта:

```powershell
& '.\Калькулятор зрелости.exe' --self-test '.\Проверки\reference-cases.json' '.\Результат-проверки'
```

Проверка выполняется без окна и пишет `verification.json` в указанную папку. Поле `pass: true` означает успех.
