# Калькулятор зрелости 1.7.1 — любой объект оценки

Оценка уровня зрелости деятельности по защите информации по Методике ФСТЭК России от 07.08.2026. Одна оценка — одна область оценки: один объект защиты (ГИС, ИСПДн, значимый объект КИИ, АСУ ТП, иная система) или несколько объектов, защищаемых одними людьми и регламентами.

## Порядок работы

1. **Объект оценки.** Организация, наименование объекта, тип объекта защиты с классом / уровнем защищённости / категорией (можно несколько типов). Минимальный целевой уровень (п. 11) и основания требований выставляются сами по самому строгому типу. Ниже — состав объекта, внешние взаимодействия (или «нет»), средства защиты и применяемые технологии. Все списки дополняются кнопкой «+ Добавить»; названия выбираются из подсказок или вводятся вручную.
2. **Анкета.** 21 направление × 8 видов требований. Кнопка «Общий ответ для всех направлений ▾» раскрывает над таблицей строку, которая заполняет все направления сразу; отличия правятся в строках и сохраняются. По умолчанию строка скрыта. После общего ответа, массового заполнения или повтора ответов направления внизу окна появляется «Отменить заполнение»: она возвращает прежние значения ячеек, изменённых этим действием, и не трогает ответы, исправленные вручную после него. Кнопка «Исключить неприменимые направления» появляется, если в описании объекта технология отмечена «Нет» (п. 13), и записывает основание исключения.
3. **Результат** — Узи, профиль, уровни по направлениям.
4. **План улучшений** — мероприятия по недостигнутым целям; ответственный и срок для каждой строки, общие значения подставляются в пустые. Неоценённые виды требований показываются отдельно и в план не входят.
5. **Сведения для отчёта** — реквизиты, лица и контакты, исходные данные, методы и инструменты, предыдущая оценка (п. 35). Вверху раздела — что ещё не заполнено.

**Отчёт ▾**: Word, Excel или всё в одном архиве (оценка + Word + Excel) с проверкой полноты. Отчёт построен по п. 35 а–н и п. 36 Методики.

## Сохранение — четыре вида файлов

| Что | Как | Файл |
|---|---|---|
| Оценка | «Сохранить» (Ctrl+S), «Ещё → Сохранить как…»; работа также сохраняется автоматически | `.uzi.json` |
| Отчёт | «Отчёт ▾» | `.docx`, `.xlsx` или `.zip` |
| Шаблон объекта | «Ещё → Шаблоны и организации…» → «Шаблоны объектов» | `.answers.json` |
| Профиль организации | там же → «Организации» (или «Профили организаций…» на вкладке сведений) | `.org.json` |

Шаблон объекта хранит описание объекта, тип и класс, ответы, область, цели, требования, исходные данные, методы и инструменты — без организации, людей, дат и материалов. Профиль организации хранит реквизиты, подписантов, контакты и участников. Шаблонов и профилей сколько угодно; папку библиотеки можно сделать общей (сетевой или облачной). Удалённое переносится в подпапку `_Удалённые`.

## Совместимость

Оценки, архивы, шаблоны и основы версий 1.0–1.6 открываются. Описание «одного АРМ» из 1.4–1.6 автоматически переводится в списки (АРМ, маршрутизатор, внешняя система, СЗИ). Формулы расчёта не менялись; сверка на 8748 эталонных случаях.
