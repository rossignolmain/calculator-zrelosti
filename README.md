# Калькулятор уровня зрелости (Узи)

Локальное Windows-приложение для оценки уровня зрелости деятельности в области защиты информации по Методике ФСТЭК России от 07.08.2026: анкета 21 направление × 8 видов требований, расчёт по таблицам 2 и 3, отчёт Word/Excel по разделу VI Методики. Интернет и Microsoft Office не нужны.

## Структура

| Путь | Что |
|---|---|
| `src/` | Исходники C# / WPF и скрипт сборки `build.ps1` |
| `docs/Руководство.md` | Руководство пользователя текущей версии (история — в git) |
| `docs/справка/` | Исследовательские записки о подключениях к внешним системам (16.10.2026), сейчас в программе не используются |
| `docs/история/` | Записка о передаче проекта от 19.10.2026 |
| `research/` | Спецификация расчёта и эталоны: 8748 комбинаций ответов исходного калькулятора |

## Сборка и проверки

Требуется Windows с .NET Framework 4.8 (компилятор `csc.exe` входит в состав).

```powershell
.\src\build.ps1 -OutputPath .\build\Калькулятор.exe
.\build\Калькулятор.exe --self-test .\research\reference-cases.json .\build\check
.\build\Калькулятор.exe --ui-self-test .\build\ui-check
.\build\Калькулятор.exe --render-preview .\build\preview
```

`--self-test` сверяет расчёт с эталонами и проверяет модель, отчёты и файлы; `--ui-self-test` проверяет интерфейс в памяти, без показа окон; `--render-preview` сохраняет снимки экранов. Результаты — JSON-файлы в указанных папках.
