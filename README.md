# Калькулятор уровня зрелости (Узи)

Локальное Windows-приложение для оценки уровня зрелости деятельности в области защиты информации по Методике ФСТЭК России от 07.08.2026: анкета 21 направление × 8 видов требований, расчёт по таблицам 2 и 3, отчёт Word/Excel по разделу VI Методики. Интернет и Microsoft Office не нужны.

## Установка

Программа — один файл `.exe`, устанавливать ничего не нужно.

1. Откройте страницу последней версии: **[Releases → Latest](../../releases/latest)**.
2. В блоке **Assets** нажмите на файл `calculator-zrelosti-<версия>.exe` — начнётся скачивание. Если браузер спросит, сохранить ли файл, выберите «Сохранить».
3. Создайте отдельную папку, например `Документы\Калькулятор зрелости`, и перенесите туда скачанный файл. Рядом с ним программа создаст папку `Данные` для автосохранения и шаблонов, поэтому не запускайте её из `Program Files` или из архива.
4. Запустите файл двойным щелчком. При первом запуске Windows может показать окно «Система Windows защитила ваш компьютер»: программа не подписана цифровой подписью. Нажмите **«Подробнее» → «Выполнить в любом случае»**. Это нужно сделать один раз.
5. При желании создайте ярлык: правый щелчок по файлу → «Отправить» → «Рабочий стол (создать ярлык)».

**Требования:** Windows 10 (версия 1903 и новее) или Windows 11 — нужная платформа .NET Framework 4.8 в них уже есть. Права администратора, интернет и Microsoft Office не нужны.

**Обновление:** скачайте новую версию и положите её в ту же папку. Папка `Данные` и сохранённые оценки (`.uzi.json`) остаются и открываются в новой версии; старый `.exe` можно удалить.

**Удаление:** удалите папку с программой.

**Проверка файла:** в описании каждого релиза указана контрольная сумма SHA-256. Сравнить: `Get-FileHash .\calculator-zrelosti-<версия>.exe` в PowerShell.

## Сборка из исходников и проверки

Для разработчиков. Требуется Windows с .NET Framework 4.8 (компилятор `csc.exe` входит в состав).

```powershell
.\src\build.ps1 -OutputPath .\build\Калькулятор.exe
.\build\Калькулятор.exe --self-test .\research\reference-cases.json .\build\check
.\build\Калькулятор.exe --ui-self-test .\build\ui-check
.\build\Калькулятор.exe --render-preview .\build\preview
```

`--self-test` сверяет расчёт с эталонами и проверяет модель, отчёты и файлы; `--ui-self-test` проверяет интерфейс в памяти, без показа окон; `--render-preview` сохраняет снимки экранов. Результаты — JSON-файлы в указанных папках.
